# CP v2 + «الملف التعريفي» Admin Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved v2 public profile at `/cp/ar` behind a dashboard-published flag, give the owner a dashboard tab that edits everything editable on that page (contacts, copy, manual figures, showcase units from Hostaway, reviews, screenshots, leads) with preview → guard → publish → rollback, and extend the disclosure guard with every figure in `docs/cp/data-seed-2026-08.md` — without ever weakening it.

**Architecture:** One overlay file `$STATE_DIR/cp_admin.json` (defaults ← overlay merge; repo `cp/data/*.json` stay the defaults). The public render reads the last **published** overlay; the dashboard preview reads the working overlay. Every admin write follows validate → render → `guard.scan` → save; a guard hit blocks the save. The showcase reads the existing `_gw_cache` through new `HOST` capabilities — no second Hostaway client, no Hostaway call on the public path. `cp/` continues to never import `bot.py`.

**Tech Stack:** Python 3, aiohttp, server-rendered HTML, vanilla JS inside `DASHBOARD_HTML`, unittest, Playwright + Lighthouse for evidence, pytesseract (the one new dependency, CI-optional).

**BLOCKER (Gate 1):** `docs/cp/v6-mock.html` — the approved design — is not on this machine (searched Downloads/Desktop/Documents). Tasks 11–15 (the public page itself) are specified but cannot start until the file lands. Everything else (guard, store, admin API, dashboard tab, picker, leads, shots) is independent and proceeds first.

## The `cp_admin.json` schema (v1 — exact)

```json
{
  "schema_version": 1,
  "published_version": "v1",
  "updated_at": "2026-08-27T10:00:00+03:00",
  "updated_by": "user_id",
  "contacts": {
    "whatsapp": "966533779297", "email": "Info@oujares.com",
    "booking_link": "", "booking_modes": {"online": true, "office": true},
    "office_label_ar": "في مكتبنا · الرياض", "slots": ["am", "pm", "eve"],
    "lead_channel_id": "", "pdf_path": "", "english_ready": false
  },
  "copy": {},
  "figures_manual": {},
  "benchmarks": {},
  "showcase": {"max": 6, "units": []},
  "reviews": {"ids": []},
  "shots": [],
  "history": []
}
```

Merge precedence at render: repo defaults (`cp/data/*.json`) ← published overlay section-by-section, key-by-key; an empty/absent overlay key falls through to the default; `figures_manual` entries missing any of value/as_of/source are dropped (v1 rule). Preview renders the **working** overlay; the public page renders `history[-1]`-equivalent published copy stored at publish time. `history` keeps the last 10 `{at, by, version, overlay}`.
