0TL;DR

A new cp/ Python package inside the Ouja-Turnover bot serves a public, Arabic-first company profile. The copy is the owner-approved document ported byte-for-byte by script (never retyped); every figure carries a source and date; a disclosure guard runs on the render path and kills any page carrying a withheld or retired figure; the numbers refresh nightly behind sanity gates. The English edition does not exist yet and honestly redirects. The old /business page is untouched.

2What was built — module map

cp/guard.py — disclosure guard

Scans rendered HTML (visible text + meta/alt/aria attributes, styles and scripts stripped, Arabic-Indic digits folded to ASCII) and raises DisclosureError on any withheld (seeds §3) or retired (seeds §11) figure. Runs inside render_ar(), not only in CI. Distinctive numbers match bare; ambiguous small ones (945, 606, 455, 278, 1,859) match only in their leaking context — because live metrics can innocently reach them. ADR 582/654 and RevPAR 451/485 whitelisted per seeds.

cp/stats.py — figure layer

Every figure is a cell {value, source, as_of} with source ∈ hostaway / manual / seeds. All 45 fields have permanent fallbacks equal to the seeds values. Only hostaway-provenance fields can be overlaid by the nightly snapshot, only when non-empty. sync_stamp() makes the page structurally unable to claim a nightly refresh that didn't happen.

cp/tools/tokenise_source.py — the port

Converts the approved Arabic document into cp/templates/ar.html by ~91 literal substitutions, each with an exact expected occurrence count; a mismatch aborts. Three rule classes, labelled in-file: figure/link tokens, PORT FIX (layout only: the RTL skip-link overflow, the .cols-2 grid), and OWNER CORRECTION (dated: the compound names). Re-running against a re-approved document re-applies everything.

cp/page.py — renderer

Fills tokens via .replace() (never f-strings; zero backslashes). Rebuilds from data: the five audience doors, the occupancy-by-type table (vs-market column computed), all bar widths, six review slots, six unit tiles, the ask, the head tags. Empty inputs degrade to the document's own coloured blanks. Missing WhatsApp → disabled button; missing email → no mailto at all.

cp/routes.py — HTTP

All public; errors return clean JSON, never a stack trace. Leads: validate → write to cp_leads.json on disk first → then Discord notify (survives Discord being down) → rate limit 8/hour/IP → field whitelist (name, company, phone, message, audience∈5). The /business 301 exists but is gated behind CP_REDIRECT_BUSINESS=1.

cp/snapshot.py — nightly refresh

03:20 Riyadh loop in bot.py, one Hostaway sweep behind the existing token-bucket throttle. Deliberately narrow: refreshes counts, nights, stay shape, repeat rates, Thu/Fri share, review scores. Does not compute occupancy / ADR / RevPAR (methodology not reconciled — see §12). Sanity gates: totals monotonic vs seeds, shares in band, unowned fields dropped, nothing-survived → nothing written. Half-up rounding (Python's banker's rounding printed 4.62 for 4.625).

Plus cp/assets/ (favicon 64/192/512 + 1200×630 share card generated from the owner's logo.PNG, composed on the logo's own ground rgb(226,226,222)), and five test files: test_cp_guard, test_cp_stats, test_cp_page, test_cp_routes, test_cp_snapshot — ~120 cp tests inside the repo's 3,435.

bot.py footprint (kept minimal): an import guard (_HAS_CP), one wiring block (cp.wire({...}) + register_routes), the nightly loop, one line in _ROLE_EXEMPT_WRITES. Photos resolve through the existing /stay pipeline (_gw_find_by_slug_or_id → _gw_listing_public) and the existing /elite/img WebP proxy — no second image system exists.

7The disclosure guard — what can never render

Blocked everywhere (page + meta + alt, both digit systems): all revenue totals and per-type/per-channel revenue, fee and payout percentages, the 53/19 active-stopped split, avg/median booking values, the 455 unsigned agreements, named best/worst residences (H8 VLG, 11B Royal), the CR number 7050158810 and فال licence number 1200050611 (page-level; PDF may carry them later), any mention of the tourism facility-management licence, the 7.6× revenue multiple, and every retired figure (7,311 · 11,307 · 14,000 turnovers · 100+/70+/72/71/67/60 unit counts · 49,000/45,000/57,600 lines · 4.8 rating).

Explicitly allowed and regression-locked: ADR 582/654, RevPAR 451/485, the seeds §3 publishable ratios (e.g. "6% of bookings, 26% of revenue"), per-residence tourism permits, the soft فال wording, and innocent numeric collisions ("945 ضيفاً عادوا" passes; "متوسط قيمة الحجز 945 ريال" fails).

Historical note for the auditor: pointed at the still-live /business, this guard finds 5 unique violations per edition (the stale 7,311 / 11,307 / 14,000 / 100+ / 49,000). That page also renders "100M+ views", "70,000+ followers" and "~14,000 turnovers" — figures absent from the seeds file.

⚠ The journey gap an auditor should weigh first

The approved document contains no lead form — its CTAs are mailto/wa.me links, and that is exactly what shipped. The backend POST /api/cp/lead (validation, disk persistence, rate limit, Discord embed) was built to the superprompt's spec and works — but nothing on the page calls it yet. Consequences: leads currently depend on the visitor's mail app or WhatsApp actually opening (desktop mailto is notoriously lossy for institutional readers); there is no inline-success flow; nothing lands in cp_leads.json; and CP_LEAD_CHANNEL_ID is unset anyway. Deciding whether to add an on-page form (3 fields + audience) wired to the existing endpoint — with the wa.me fallback the superprompt describes — is probably the single highest-leverage improvement available.

11Found only on the live deploy

Both were invisible to local tests because those build a bare aiohttp app without bot.py's middlewares. Both are now regression-locked.

  1. The lead endpoint returned 401. bot.py's global role middleware blocks any POST not in _ROLE_EXEMPT_WRITES. /api/cp/lead was added beside /api/decor/inquire; a test now pins the exemption. Lesson for any future public POST route in this repo.
  2. The og:image tag was silently absent. PUBLIC_BASE_URL is unset on Railway and the wiring froze base_url at startup. HOST.base_url now accepts a callable; bot.py wires _dispatch_base_url (env → auto-captured public host → site default), resolved per render.

Also observed live, not a defect: /stay returns 404 because the guest-site pause switch (24 Aug work) is active; its /api/stay/* endpoints still serve.
